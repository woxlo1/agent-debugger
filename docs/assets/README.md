# Assets

| File | Purpose |
|---|---|
| `icon.svg` | Primary square app icon. Use for README, GitHub profile, and desktop shell. |

| `social-card.svg` | 1200x630 Open Graph / Twitter card source. |

All assets are original and MIT licensed with the repository. `demo.gif` was captured from the local browser-based desktop shell after importing only `docs/examples/failed-trace.ndjson`; no real customer content, credentials, external service responses, or participant data appear in it.

The SVGs are the source of truth. Export raster sizes from them with your preferred SVG renderer when a bitmap is required; do not hand-edit generated PNGs.
