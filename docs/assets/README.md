# Assets

| File | Purpose |
|---|---|
| `icon.svg` | Primary square app icon. Use for README, GitHub profile, and desktop shell. |
| `favicon.svg` | Simplified 64px mark for the docs site and web app. |
| `social-card.svg` | 1200x630 Open Graph / Twitter card source. |
| `demo.gif` | 900x506 screen capture of the local web UI replaying the synthetic failed checkout trace. |

All assets are original and MIT licensed with the repository. `demo.gif` contains only synthetic data from `docs/examples/failed-trace.ndjson`; no real customer content, credentials, or external service responses appear in it.

The SVGs are the source of truth. Export raster sizes from them with your preferred SVG renderer when a bitmap is required; do not hand-edit generated PNGs.
